# Сервис услуг - Варианты использования

## ВИ: просмотр списка услуг
**ID:** 1  
**Краткое описание:** просмотр доступных услуг в маркетплейсе  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** нет  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Маркетплейс услуг"

**Основной поток:**
1. Вариант использования начинается, когда пользователь открывает раздел услуг
2. Система отображает список услуг с:
   - Названием
   - Описанием
   - Категорией
   - Ценой и типом оплаты (фиксированная, почасовая, пакетная)
   - Рейтингом исполнителя
   - Типом объявления (запрос услуги или предложение услуги)
3. Пользователь может фильтровать услуги по категории, типу объявления или цене
4. Пользователь может сортировать услуги по рейтингу, цене или дате создания
5. Пользователь может выбрать услугу для просмотра подробностей

**Альтернативные потоки:**
1. Поиск услуги

---

**Второстепенное действующее лицо:** нет

## ВИ: просмотр подробностей услуги
**ID:** 2  
**Краткое описание:** просмотр детальной информации об услуге  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** нет  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Маркетплейс услуг"
3. Услуга существует

**Основной поток:**
1. Вариант использования начинается, когда пользователь выбирает услугу из списка
2. Система увеличивает счетчик просмотров услуги
3. Система отображает подробную информацию об услуге:
   - Название
   - Подробное описание
   - Категория
   - Тип объявления (запрос или предложение)
   - Цена и тип ценообразования
   - Размер залога (если применимо)
   - Теги и требуемые навыки
   - Местоположение
   - Расписание доступности (дни и временные слоты)
   - Рейтинг и количество отзывов
   - Количество выполненных заказов
   - Портфолио и вложения
4. Система отображает информацию об исполнителе/заказчике
5. Пользователь может откликнуться на услугу или связаться с автором объявления

## ВИ: создание объявления об услуге
**ID:** 3  
**Краткое описание:** создание нового объявления об услуге  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** нет  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Маркетплейс услуг"

**Основной поток:**
1. Вариант использования начинается, когда пользователь выбирает опцию "Создать объявление"
2. Система отображает интерфейс создания объявления
3. Пользователь выбирает тип объявления (запрос услуги или предложение услуги)
4. Пользователь вводит название услуги
5. Пользователь вводит описание услуги
6. Пользователь выбирает категорию
7. Пользователь указывает цену
8. Пользователь выбирает тип ценообразования (фиксированная цена, почасовая оплата или пакет)
9. При необходимости пользователь добавляет:
   - Размер залога
   - Теги
   - Требуемые навыки
   - Местоположение
   - Расписание доступности
   - Примеры работ (портфолио)
   - Дополнительные файлы
10. Пользователь нажимает кнопку "Создать"
11. Система создает объявление со статусом "активно"
12. Система отображает объявление в списке
13. Система рассылает уведомление заинтересованным пользователям

**Альтернативные потоки:**
1. Отмена создания

## ВИ: отклик на объявление
**ID:** 8  
**Краткое описание:** создание заявки на услугу  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** автор объявления  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Маркетплейс услуг"
3. Объявление существует и активно
4. Пользователь не является автором объявления
5. У пользователя достаточно средств на балансе для оплаты залога (если требуется)

**Основной поток:**
1. Вариант использования начинается, когда пользователь выбирает опцию "Откликнуться" на объявление
2. Система отображает интерфейс создания заявки
3. Пользователь указывает цену (может отличаться от указанной в объявлении)
4. Пользователь вводит сообщение с деталями заказа
5. При необходимости пользователь указывает:
   - Планируемую дату выполнения
   - Срок выполнения
   - Адрес (если требуется)
   - Дополнительные файлы
6. Пользователь нажимает кнопку "Отправить заявку"
7. Система создает заявку со статусом "ожидает ответа"
8. Если требуется залог, система резервирует средства на балансе пользователя
9. Система создает чат для общения между заказчиком и исполнителем
10. Система отправляет уведомление автору объявления о новой заявке

**Альтернативные потоки:**
1. Недостаточно средств для залога
2. Отмена создания заявки

---
