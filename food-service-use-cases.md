# Сервис еды - Варианты использования

## ВИ: просмотр меню
**ID:** 1  
**Краткое описание:** просмотр доступных блюд и меню  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** нет  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Столовая"

**Основной поток:**
1. Вариант использования начинается, когда пользователь открывает раздел меню
2. Система отображает категории блюд
3. Система отображает доступные блюда с названиями, описаниями, ценами и изображениями
4. Пользователь может выбрать категорию для фильтрации блюд
5. Система отображает блюда выбранной категории

**Альтернативные потоки:**
1. Поиск блюда

## ВИ: создание заказа
**ID:** 5  
**Краткое описание:** оформление и создание заказа  
**Основное действующие лицо:** пользователь  
**Второстепенное действующее лицо:** нет  

**Предусловия:**
1. Пользователь авторизован в системе
2. Пользователь открыл сервис "Столовая"
3. В корзине есть блюда
4. У пользователя достаточно средств на балансе

**Основной поток:**
1. Вариант использования начинается, когда пользователь нажимает кнопку "Оформить заказ" в корзине
2. Система отображает интерфейс оформления заказа
3. Пользователь выбирает способ получения заказа (в зале, самовывоз, доставка)
4. Если выбран способ "в зале", пользователь указывает номер столика
5. Если выбран способ "доставка", пользователь указывает адрес доставки
6. Система отображает итоговую стоимость заказа с учетом комиссии (если применимо)
7. Пользователь подтверждает заказ
8. Система списывает средства с баланса пользователя
9. Система создает заказ со статусом "создан"
10. Система очищает корзину
11. Система отображает номер заказа и информацию о нем
12. Система отправляет уведомление о создании заказа

**Альтернативные потоки:**
1. Недостаточно средств на балансе
2. Отмена оформления заказа

---
